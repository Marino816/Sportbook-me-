## Usage Rules

- Always use the full product name on first reference
- "SB ME Intelligent AI" is acceptable on subsequent references
- Never shorten to "SBM" — this is the old deprecated name
- The 🧠 emoji is optional in code but required in marketing
- The ™ symbol is required on first reference in customer-facing materials

---

## Prohibited

- ❌ "SBM Intelligent AI" (deprecated)
- ❌ "SBM AI"
- ❌ "SBME" (without space)
- ❌ Any lowercase "sb me" in branding context

---

## File Naming

- Use `sb_me` for files and identifiers (lowercase, underscore)
- Example: `sb_me_ai_chat.tsx`, `sb_me_preferences.json`
