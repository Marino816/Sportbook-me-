## 2. How We Use Information

- To provide DFS intelligence and lineup optimization services

## 3. Data Storage

- All data stored in PostgreSQL on Railway (US region)
- Session tokens (JWT) stored in browser localStorage
- No credit card data stored — handled by Stripe

---

## 4. Data Sharing

We do not sell user data. Data may be shared with:

- Stripe (payment processing)
- Railway (infrastructure hosting)
- Vercel (frontend hosting)

## 5. Data Retention

- Stripe events: retained for audit (1 year)

## 7. Security

- Passwords hashed with bcrypt
- JWT tokens with HS256 encryption
- HTTPS enforced on all endpoints
